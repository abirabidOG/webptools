Convert the given image (or images) to optimised WebP using the webptools
skill.

Use the webptools skill to convert `$ARGUMENTS` to WebP, locally, with the
bundled sharp script. Report each output file with its before and after size
and the measured saving. Never promise a fixed saving: the live page states
images can shrink by up to 35%.
